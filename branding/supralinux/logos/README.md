# Logos de SupraLINUX

Variantes convertidas desde los originales de SupraLINUX:

- `supralinux-light-*`: `SupraLINUX_Claro.png`, para fondos claros.
- `supralinux-dark-*`: `SupraLINUX_Oscuro.png`, para fondos oscuros.
- `supralinux-color-*`: `SupraLINUX_Color.png`, para splash, instalador y
  usos donde el color es aceptable.
- `supralinux-white-blue-*`: círculo claro con letras azules, para el menú
  inicio como opción seleccionable.

Tamaños: 16, 22, 24, 32, 48, 64, 96, 128, 256 y 512 px. Todos conservan el
canal alfa original.

Cada variante incluye además el SVG original (`supralinux-color.svg`,
`supralinux-light.svg`, `supralinux-dark.svg`, `supralinux-white-blue.svg`),
con el texto convertido a trayectos para no depender de la fuente Ubuntu en
tiempo de render. No hay PNG embebido. El menú inicio usa Color por defecto;
Light, Dark y White-Blue quedan disponibles como iconos seleccionables.
- `fastfetch-logo.txt`: arte ASCII de 24 líneas usado por fastfetch
  (el paquete lo instala con el azul de la marca).
- `fastfetch-logo-color.txt`: versión con los tres colores de la marca
  (aro `#F6F6F6`, fondo `#51A2DA`, letras `#FFFFFF`); es la que instala
  el paquete por defecto.
