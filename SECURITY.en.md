# Security policy

SupraLINUX is a personal project. Security is handled responsibly, with no
SLA or commercial support.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Older | No |

## KDE or Ubuntu issues

Report them through the official KDE or Ubuntu channels. SupraLINUX rebuilds
and publishes updates when needed.

## SupraLINUX issues

This covers packaging, defaults, installer, repository, keys, permissions,
privileged scripts, theme, and system settings.

Report privately:

1. `https://supralinux.com/bugs.html`, marking “security” in the summary.
2. Once the repository is public, a private security advisory will be enabled
   (GitHub Security Advisory or equivalent).

Do not open public issues for vulnerabilities.

## What to include

- SupraLINUX version.
- Steps to reproduce.
- Impact and whether the issue is exploitable.
- Relevant logs.
- Configuration that differs from the defaults.

Do not include third-party personal data.

## Response time

Best-effort, no SLA. Issues with real impact are prioritized.

## GPG key

The release key fingerprint will be published with the 1.0.0 release.
